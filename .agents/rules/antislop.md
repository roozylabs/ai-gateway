# antislop

Antislop: the anti-AI-slop filter for all UI, copy, and code-comment work in this repository. For UI, copy, people, mobile layout, or code comments work, read the core filter and then the skill for the task:

- Core filter: `.agents/skills/antislop/SKILL.md`
- Design direction (read before building UI): `.agents/skills/antislop/DESIGN.md`
- UI / visual: `.agents/skills/antislop-ui/SKILL.md`
- Copy & text: `.agents/skills/antislop-copywriting/SKILL.md`
- People / accessibility: `.agents/skills/antislop-human/SKILL.md`
- Mobile / responsive: `.agents/skills/antislop-layoutmobile/SKILL.md`
- Code comments: `.agents/skills/antislop-code/SKILL.md`

Before starting UI work, ask the user when antislop applies: during the work, or after it is done.
