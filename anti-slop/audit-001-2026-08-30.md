# Audit 001 - AntiSloP Findings

- **Date:** 30 August 2026
- **Scope:** `apps/app` (23 pages + 87 `.tsx` components), applied with the core filter and the UI, Copywriting, Layout/Mobile, and Code skills. `DESIGN.md` loaded for direction (dials ENERGY 1 / RHYTHM 2 / MOTION 1).
- **Mode:** AFTER (audit of the existing app, then apply).
- **Result:** The app is largely deliberate and clean. Most slop tells are absent (no gradients, glow, pill-radius, emoji, buzzwords, Sparkles, fabricated data). The one Hard-Gate defect is em-dash usage (R-02). The rest are retained with a written reason per the purpose test.

---

## Findings (numbered)

### HIGH (Hard Gate)

- **F1 - R-02 (em dash in prose/metadata).** Em dash used in human-facing text:
  - `apps/app/app/layout.tsx:22` title: `RoozyLabs Prism — Universal AI Control Plane`
  - `apps/app/app/(dashboard)/tools/_components/ToolFormDialog.tsx:299` helper text: `... — defines the function-call arguments ...`
  - `apps/app/app/(dashboard)/mcp/_components/MCPTestModal.tsx:545` helper text: `This tool declares no input schema — it will be called with`
  - Fix: replace with a colon or comma. Layout title: `RoozyLabs Prism: Universal AI Control Plane`.

### MEDIUM (Hard Gate, consistency)

- **F2 - R-02 (em dash as null placeholder).** `—` used as an empty-value placeholder in data tables. This is a deliberate console convention but still emits the R-02 character. Replace with `-`:
  - `apps/app/app/(dashboard)/logs/page.tsx:42` and `:197`
  - `apps/app/app/(dashboard)/budgets/page.tsx:117`
  - `apps/app/app/(dashboard)/playground/page.tsx:47` and `:48`
  - `apps/app/app/(dashboard)/page.tsx:166`, `:173`, `:180`, `:187`
  - `apps/app/app/(dashboard)/models/page.tsx:67`, `:83`, `:84`
  - `apps/app/app/(dashboard)/providers/page.tsx:84`
  - Reason for alternative: `-` reads as a clean "no value" marker in a dense table and avoids the R-02 character.

### HIGH (Hard Gate - R-25 color contrast)

- **F10 - R-25 (violet `#8B5CF6` as small text on light backgrounds).** `#8B5CF6` measures ~4.23:1 against white, which fails WCAG AA 4.5:1 for normal-size text (it passes 3:1 for icons and large/brand text). The affected **text** usages are:
  - `apps/app/components/AppLayout.tsx:155` (active nav route label) and `:163` (paired icon) and `:184` (avatar fallback initials)
  - `apps/app/app/(dashboard)/audit-trail/page.tsx:88` (mono request id)
  - `apps/app/app/(dashboard)/playground/page.tsx:159` (top-match score) and `:169` (candidate rank `#`)
  - Fix: use the darker violet `#7C3AED` (violet-600) for these text usages, which measures ~5.7:1 and passes AA. `#7C3AED` is already a palette neighbor (`prismViolet` button hover in `Button.tsx`). Brand `#8B5CF6` is retained for icons/graphical surfaces (3:1 pass) and the large auth wordmark.
  - Retained with reason: `ChartContainer.tsx:27` chart-tooltip value sits on a designed dark console surface (`bg-slate-950/95`) where its bold value reads at ~4.4:1 - a data-viz overlay, not body text.

### Retained with reason (purpose test PASS; not defects)

- **F3 - R-06 (uppercase mono micro-labels).** Sidebar group labels, table column headers, metric-card labels, field labels use `uppercase tracking-wider` with mono. These are **data-hierarchy micro-labels for a dense developer control plane**, not marketing section headers (`FEATURES`, `HOW IT WORKS`). The console identity is recorded in `DESIGN.md`. Retained; reason written.
- **F4 - R-04 (Lucide icons).** All icons are lucide-react. The repo rule `.agents/rules/ui-icon-guidelines.md` and `DESIGN.md` mandate this control-plane icon family, and the glyphs are task-relevant. The `Bot` icon used for "Agent Gateway" / agents represents agents semantically. Retained; reason written.
- **F5 - R-10 (glassmorphism).** `backdrop-blur` on the sticky top header (`AppLayout.tsx:200`), a chart tooltip (`ChartContainer.tsx:20`), and one status widget (`ModelActivityWidget.tsx:117`). These are three separate functional surfaces, not a page-wide glass default. Retained; reason written.
- **F6 - R-19 (motion).** All `animate-spin`/`animate-pulse` are functional loading indicators, skeletons, and active-status pulses. No decorative endless loops. Retained.
- **F7 - R-01 (violet active-nav stripe).** The violet left stripe in `AppLayout.tsx:161` marks the active nav item (real state signal), not decoration. Retained.
- **F8 - R-12 / R-13 (shadows).** Shadows are elevation-only (tooltips, dropdowns, dialogs, auth cards). No page-wide floating shadow or glow. Retained.
